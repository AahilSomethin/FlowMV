# Working in FlowMV

Use your own account and select the intended workspace in the header. Requests are submissions you can track; My Tasks contains work you can act on. Workflows describe the process. A workspace role does not automatically allow every internal action or credential operation.

## Employee

Start a request from a published workflow, complete its defined form and follow the timeline. If a revision is requested, open the assigned task and correct the information in FlowMV; a chat reply alone does not change protected data. View only authorized evidence. Employees cannot create template drafts, preview authoring definitions or publish workflows. Ask an Admin for approved provider access rather than sharing tokens.

## Manager

Open My Tasks and review the actual request and decision evidence. Approve/reject only eligible tasks; the submitter cannot approve their own request. Complete assigned work and explain corrections through the intended workflow. Linked Telegram approval buttons are expiring shortcuts to the same authorization checks, not a grant of Manager permissions. Use the FlowMV link to inspect the full request. Managers with authoring permission may create and configure drafts; an Admin publishes.

## Administrator

Manage membership and provider policy carefully. Shared credentials need connection approval, approved destinations and explicit workflow operation grants. Personal ownership remains separate and private. Approve only the minimal read/send scope required. Disabling pauses relevant intake; revocation removes credential use. Review uncertain deliveries before retrying. Do not grant service access simply because the provider is connected.

## Builder and templates

Open Workflows → Explore templates, filter a category and review roles, permissions, main path and expected outcome. Provider templates require binding through the wizard. If setup is missing, follow the provider setup link; the wizard cannot invent a connection ID. Creation produces an editable draft. Use search, tidy layout, undo/redo and node configuration guidance. Save with the current revision, resolve validation findings and ask an Admin to publish. Unsaved-change protection remains active. On mobile use the read-only presentation and return to desktop for full authoring.

Hypothetical preview accepts synthetic answers and explicit assumed decisions. It shows executed/skipped/blocked nodes and branches; it never creates requests, decrypts credentials or sends messages. Correction loops reuse synthetic inputs. Unsupported behavior is unavailable. Use the isolated guided demo for real task/revision/outbox processing.

Published-version comparison reports structural changes only. It excludes raw configuration values, credential references, submissions and messages. A published version remains immutable and running requests stay pinned to their original contract.

## Connections and analytics

Connection cards show safe status and recorded operation provenance. “Simulated operation” is local evidence. “Provider response recorded” means a provider response was recorded, not confirmed recipient delivery. Older history without provenance remains unknown. Open provider setup to inspect grants, destinations and permitted read/send behavior. Tokens are never shown after storage.

Analytics is generated from authorized application records and uses UTC periods. Admin scope is organization-wide; other roles are limited to visible requests. Minimum sample size is five for protected rates/durations; a suppressed number is not zero. Audit and decision snapshots explain the pinned version and human actions without revealing private message content.

## AI suggestions

[AI connections](../integrations/ai.md) require organization consent and exact workflow permissions. Employees submit and correct through authenticated FlowMV forms. Managers review original evidence alongside advisory summaries; advice never replaces eligibility checks or a human decision. Admins manage organization keys and policy; personal keys remain private even during metadata approval review. Draft replies stay unsent.
